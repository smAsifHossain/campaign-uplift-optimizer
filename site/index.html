Methodology

How the analysis was built

Every published number is generated from versioned code, validated artifacts, and a documented evaluation contract.

Acquire

Official Criteo v2.1 archive, source attribution, checksum and schema validation.

Split

Stable feature hashing prevents identical covariate groups crossing data splits.

Select

Causal candidates compete on validation AUUC above a random policy.

Evaluate

One locked test set produces policy curves, uncertainty and calibration.

Decide

Scenario economics combine incremental effect, reach, cost and value.

Reproduce it

Core commands

python -m campaign_uplift acquire
